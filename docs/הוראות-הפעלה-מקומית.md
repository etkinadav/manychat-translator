# הוראות הפעלה מקומית — Manychat Translator

מסמך זה מסכם את כל הפעולות הנדרשות להרצת המערכת על המחשב שלך:
**שרת Node.js מקומי** + **הרחבת Chrome** על אתר Manychat.

---

## מה המערכת עושה?

| חלק | תפקיד |
|-----|--------|
| **Backend** (`backend/`) | שרת תרגום מקומי על פורט 3000. מתרגם דרך Google Translate. |
| **Extension** (`extension/`) | הרחבת Chrome שמזהה הודעות ב-Manychat ומתרגמת אותן. |

**כיווני תרגום:**
- הודעות נכנסות בצ'אט: עברית → אנגלית
- תיבת תשובה (textarea): אנגלית → עברית (כפתור "Translate to Hebrew")

---

## דרישות מוקדמות (פעם אחת)

1. **Node.js** מותקן (גרסה 18 ומעלה מומלצת)  
   בדיקה: `node -v`

2. **Google Chrome**

3. **Google Cloud SDK (`gcloud`)** — לתרגום אמיתי  
   - התחברות: `gcloud auth application-default login`  
   - הפעלת API:  
     ```powershell
     gcloud services enable translate.googleapis.com --project=screen-translator-496203
     ```

4. **קובץ `.env` בשרת** — כבר קיים ב-`backend/.env`:
   ```
   GOOGLE_CLOUD_PROJECT=screen-translator-496203
   ```

## התקנה ראשונית (פעם אחת בלבד)

פתח **שני** חלונות PowerShell (או טרמינל).

### חלון 1 — Backend

```powershell
cd "C:\Users\User\Desktop\programming\manychat translator\backend"
npm install
```

### חלון 2 — Extension

```powershell
cd "C:\Users\User\Desktop\programming\manychat translator\extension"
npm install
npm run build
```

### טעינת ההרחבה ל-Chrome (פעם אחת)

1. פתח: `chrome://extensions`
2. הפעל **מצב מפתחים** (Developer mode) בפינה הימנית העליונה
3. לחץ **Load unpacked** (טען ללא אריזה)
4. בחר את התיקייה:  
   `C:\Users\User\Desktop\programming\manychat translator\extension\dist`

> **חשוב:** טוענים את `extension\dist`, לא את `extension` עצמה.

## הפעלה יומיומית (כל פעם שעובדים)

### שלב 1 — הפעלת השרת

```powershell
cd "C:\Users\User\Desktop\programming\manychat translator\backend"

**מה אמור להופיע בלוג:**

```

[gtranslate] projectId source: env

השאר את הטרמינל **פתוח** כל עוד אתה עובד.

### שלב 2 — פתיחת Manychat

1. פתח Chrome
2. גש ל: `https://app.manychat.com/.../chat/...`
3. אם השרת רץ וההרחבה טעונה — תראה:
   - תרגום אנגלי מתחת להודעות עבריות
   - כפתור **Translate to Hebrew** ליד תיבת התשובה

## עדכון ההרחבה אחרי שינוי קוד

כל פעם ששינית קבצים ב-`extension/src/`:

```powershell
cd "C:\Users\User\Desktop\programming\manychat translator\extension"
npm run build
```

ואז ב-Chrome:

1. `chrome://extensions`
2. מצא **Manychat Translator**
3. לחץ על **סמל הרענון** (↻) על כרטיס ההרחבה
4. חזור לטאב Manychat ולחץ **F5** (רענון דף)

> **טיפ:** אפשר להשאיר `npm run dev` ב-extension (מצב watch) — אז הבנייה מתבצעת אוטומטית בכל שמירה. עדיין צריך Reload בהרחבה + F5 בדף.

---

## עדכון השרת אחרי שינוי קוד

אם שינית קבצים ב-`backend/src/`:

- אם `npm run dev` כבר רץ — `ts-node-dev` אמור להפעיל מחדש אוטומטית
- אם לא — עצור עם **Ctrl+C** והרץ שוב `npm run dev`

## איך לעצור / לשחרר שרת תקוע על פורט 3000

### סימנים לבעיה

```
Error: listen EADDRINUSE: address already in use :::3000
```

משמעות: תהליך ישן עדיין מחזיק את פורט 3000.

---

### אופציה א — עצירה נקייה (מומלץ)

בטרמינל שבו השרת רץ:

```
Ctrl + C
```

חכה לראות (אם מופיע):

```
[server] received SIGINT, shutting down
[server] closed cleanly
```

---

### אופציה ב — הריגת התהליך שתפוס את הפורט (Windows / PowerShell)

העתק והדבק **שורה אחת**:

```powershell
$held=(netstat -ano | Select-String ":3000\s.*LISTENING" | ForEach-Object { ($_ -split '\s+')[-1] } | Select-Object -First 1); if ($held) { Stop-Process -Id $held -Force; "נעצר PID $held" } else { "אין תהליך על פורט 3000" }
```

אחר כך הרץ שוב:

```powershell
npm run dev
```

---

### אופציה ג — שלב-שלב

**1. מצא מי מאזין לפורט 3000:**

```powershell
netstat -ano | Select-String ":3000\s"
```

בסוף השורה תופיע מספר **PID** (למשל `343828`).

**2. עצור את התהליך:**

```powershell
Stop-Process -Id 343828 -Force
```

(החלף `343828` ב-PID שמצאת)

**3. ודא שהפורט פנוי:**

```powershell
netstat -ano | Select-String ":3000\s"
```

אם אין פלט — הפורט פנוי.

## פתרון תקלות נפוצות

### `Unable to detect a Project Id`

- ודא שקיים `backend/.env` עם:
  ```
  GOOGLE_CLOUD_PROJECT=screen-translator-496203
  ```
- הפעל מחדש: `npm run dev`

### `translation failed` / `backend returned HTTP 500`

- ודא שהשרת רץ (`npm run dev` ב-`backend/`)
- בדוק לוגים בטרמינל השרת
- ודא ש-Cloud Translation API מופעל ב-GCP

### אין תרגום / אין כפתור

1. Reload בהרחבה (`chrome://extensions`)
2. F5 בדף Manychat
3. F12 → Console — חפש לוגים `[ManychatTranslator]`

### שינויים בהרחבה לא נראים

- הרצת `npm run build`?
- Reload בהרחבה?
- רענון דף Manychat (לפעמים Ctrl+Shift+R)?

## הערות

- **אין צורך ב-API Key של Google** — משתמשים ב-ADC (`gcloud auth application-default login`).
- **ההרחבה לא נשלחת הודעות אוטומטית** — תרגום בתיבת התשובה רק ממלא טקסט; שליחה ידנית ב-Manychat.
- **שני טרמינלים** — אחד לשרת (`backend`), אחד לבניית הרחבה לפי הצורך (`extension`).
